# Flex, diseño responsive y accesibilidad

Normalmente estas funcionalidades se consiguen añadiendo o modificando unas pocas líneas de código en el fichero `style.css`, en el selector adecuado.

La página representa un pequeño club de lectura con varias recomendaciones y un formulario para apuntarse a la próxima reunión.

## Ejercicio

1. Escribe una etiqueta `<title>` adecuada para esta página.

2. Establece un atributo `alt` adecuado para la última imagen. 

3. Apenas se puede leer bien el texto de la cabecera. Modifica el color de la letra para conseguir un contraste adecuado entre el texto y el fondo.

4. Fíjate en la primera regla CSS .shelter-dogs__list. Modifícala para convertir ese div en un contenedor flexible y conseguir que sus hijos pasen a la siguiente línea cuando no haya suficiente espacio horizontal. Además, establece una separación de 1rem entre las tarjetas. (3 líneas de código)

5. El campo email del formulario no es completamente accesible. Al hacer clic sobre "Tu correo electrónico", no se activa el campo input correspondiente. Modifica el HTML para asociar correctamente el label con su input.

6. Localiza la media query en esté código. Nos gustaría que el encabezado principal de esta página tomara un tamaño de la fuente de **6rem** cuando el viewport llega a un mínimo de 768px.

## Recuerda

- Prueba el resultado utilizando las herramientas de desarrollo de Chrome y cambia el tamaño del viewport.
